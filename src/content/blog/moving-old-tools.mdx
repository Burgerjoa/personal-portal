예전에 만든 `own_site`에는 글자수 세기, D-Day 계산, Base64 변환처럼 작지만 종종 다시 찾게 되는 도구들이 있었다. 새 사이트를 만들면서 이것들을 링크만 걸어둘지, 다시 만들지 고민했다.

## 그대로 옮기지 않은 이유

기존 도구는 각각 독립된 HTML과 JavaScript 파일로 동작했다. 빠르게 만들기에는 좋았지만 공통된 화면이나 상태 표현을 고치려면 같은 작업을 여러 번 해야 했다.

이번에는 기능을 React 컴포넌트로 옮기되 계산 자체는 브라우저 안에서 끝나도록 했다. 서버가 필요 없는 작업에 서버를 끼우지 않는 것이 이 도구들의 가벼운 성격에도 맞았다.

## 먼저 옮긴 것

- 입력과 동시에 결과가 필요한 글자수 세기
- 날짜 계산 규칙을 확인하기 좋은 D-Day 계산
- UTF-8 처리가 중요한 Base64 변환
- 브라우저의 `crypto.getRandomValues`를 쓰는 비밀번호 생성기

한 번에 전부 옮기지 않고 실제로 다시 쓸 가능성이 높은 것부터 골랐다. 아직 옮기지 않은 도구는 숨기기보다 다음 작업 목록으로 남겨두었다.

## 이번에 배운 점

마이그레이션은 코드를 새 문법으로 번역하는 일이 아니었다. 지금도 필요한 기능인지, 사용 흐름에서 무엇이 불편했는지 다시 판단하는 과정에 가까웠다.

앞으로 도구를 추가할 때도 원본의 기능 수보다 지금 이 사이트에서 자연스럽게 쓰이는지를 먼저 볼 생각이다.
